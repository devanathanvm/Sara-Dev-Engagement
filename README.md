# Sara & Dev — Engagement Invitation

A mobile-friendly invitation page with the original Full HD portrait video and a Google Maps directions button. No installation or build is required.

## Publish on GitHub Pages

1. Create a public GitHub repository (for example, `sara-dev-engagement`).
2. Extract this ZIP on your computer.
3. Upload `index.html`, `invitation.mp4`, and `poster.jpg` to the root of the repository. Upload the files inside the folder, rather than the ZIP or the enclosing folder.
4. In the repository, open **Settings → Pages**.
5. Select **Deploy from a branch**, choose **main** and **/(root)**, then save.
6. GitHub will show the published link on this page once deployment finishes. Share that link with guests.

If the interface differs, refer to GitHub's current Pages instructions:
https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

You can open `index.html` locally to preview it. Keep all three files in the same folder. The video starts when a guest presses play, retaining its original audio. Its playback quality is 1080 × 1920; it is prepared for progressive loading. The directions button opens the supplied Google Maps location.
